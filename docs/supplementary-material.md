# Supplementary material

The supplementary directory contains detailed research-support artifacts that are useful for reviewers but are not part of the primary getting-started path.

- [Testing and code verification strategy](supplementary_material/TESTING_REPORT.md)
- [Testing report PDF](supplementary_material/TESTING_REPORT.pdf)
- [GPT-5.2 ground-truth material](supplementary_material/GROUND_TRUTHS_GPT5.2.pdf)

The testing report explains the layered assurance model used by the repository: unit and integration regression tests, CLI checks, pre-LLM smoke audits, run-state contracts, resumability, and review artifacts. Treat it as supplementary evidence; the current commands and requirements are maintained in [Development and verification](development.md).
