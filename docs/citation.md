# Citation

## Software

If you use the software, cite the metadata in [`CITATION.cff`](https://github.com/NoeFlandre/distill-abm/blob/main/CITATION.cff). It identifies the repository, authors, release, and preferred manuscript citation.

## Manuscript

The associated article is [*Distilling the Complexity of Agent-Based Simulations into Textual Explanations via Large Language Models*](https://www.mdpi.com/2504-2289/10/4/121) by Noe Y. Flandre and Philippe J. Giabbanelli.

Use the manuscript's published citation details when citing research findings. Use `CITATION.cff` when citing the software implementation itself.
